# Learning Programs

This folder preserves the existing practice programs from the original project.

## Included topics

- Core Java fundamentals and logic programs
- Arrays, collections, lambdas, and streams
- OOP: abstraction, encapsulation, and polymorphism
- Selenium WebDriver interactions
- Alerts, windows, frames, dropdowns, actions, waits, and screenshots
- JavaScriptExecutor examples
- Reusable browser, action, cookie, Excel, and web utilities

## How to use

Import the root `qa-automation-portfolio` folder into Eclipse as a Maven project. You can browse or run individual learning programs from `learning-programs/src/test/java` as needed.

The production-style framework examples are in the sibling `selenium-ui-tests` and `rest-assured-api-tests` folders.
